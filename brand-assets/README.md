# Marketing-Asset-Vorlagen

HTML-Vorlagen für Social-/Werbebanner im BetriebsKostenBot-Look. Erneut rendern mit:

```bash
npm install playwright
npx playwright install chromium
node render.js
```

Ausgabe: `og-image.png` (1200×630), `linkedin-banner.png` (1584×396), `instagram-post.png` (1080×1080).
Fertige PNGs liegen bereits unter `public/brand/social/`.
